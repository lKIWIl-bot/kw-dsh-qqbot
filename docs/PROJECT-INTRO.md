# kw-dsh-qqbot 项目介绍

kw-dsh-qqbot是一套面向Windows本机部署的QQ智能机器人桥接与生成管理项目。它将QQ消息接入DeepSeek Harness，并通过可选的本地ComfyUI工作流提供Anima生图、LoRA和高清放大能力，图生视频由独立扩展提供，使聊天、任务排队与管理员控制在同一套QQ交互中协同运行。

## 项目定位

项目负责消息接入、身份与权限校验、对话衔接、受控生成任务和结果发送。NapCat负责QQ连接，DSH负责模型对话，ComfyUI负责本地生成；它们独立安装和运行，可复用部署者已有环境。

## 核心能力

- 支持私聊和群聊白名单，群内通过实际@或机器人昵称唤醒；生成指令必须实际@。
- 提供中文斜杠指令、普通/管理员分层帮助，以及需要本人确认和审批的远程模式。
- 默认/生图使用官方Anima Base，支持原样正负提示词、管理员批量、最多五项兼容LoRA叠加。
- LoRA放入已配置目录即可发现，支持同名JSON补充名称、触发词、权重和用途；底模不明时不强行启用。
- 普通用户默认每滚动60分钟五张，统一串行队列、发送后间隔与管理员优先；支持追加额度和生成开关。
- 正式版包含高清放大、进度查询、缓存及管线恢复；图生视频作为独立扩展安装和卸载。
- 后台绑定真实请求者、发送目标、数量和工作流，生成完成后发送结果并@请求者。

## 部署与扩展

仓库提供配置向导、状态/日志入口、doctor、公开模型来源清单和SHA256检查，以及面向人工和agent的外部组件指南。聊天可以先独立接通，生成能力逐项安装。模型、节点、角色LoRA和工作流保持明确边界，后续扩展需同步配置校验、权限和测试，不能让QQ提示词任意指定本机路径或节点图。

## 来源与发布状态

项目基于[h-D-ACE/dsh-qq](https://github.com/h-D-ACE/dsh-qq)扩展，保留桥接上游[Derpyu520/qq-bridge](https://github.com/Derpyu520/qq-bridge)的版权和MIT许可证。外部SDK、模型和节点各自适用原许可。

当前为本地公开版候选，已进行离线回归与新目录安装验证；真实生图、高清和管理员私聊发送已通过，未切换现用桥接验证完整DSH聊天路由，源码发布至GitHub；正式版及扩展见仓库Releases。已移除原先许可未决的两个SnowLuma npm依赖，详细验证范围见[VALIDATION.md](VALIDATION.md)。
