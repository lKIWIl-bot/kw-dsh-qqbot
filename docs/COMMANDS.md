# 指令

## 普通用户

| 指令 | 用途 |
| --- | --- |
| /help | 查看普通帮助 |
| /生图 描述 | 官方Anima Base生成 |
| /生图 #名称 描述 | 使用Anima LoRA，最多5项 |
| /tag生图 PST/正面词 NGT/负面词 | 原样提示词生成 |
| /loras [角色或画风] | 列出可用LoRA |
| /lora 名称 | 查看说明 |
| /生图状态、/生图队列 | 查询任务 |
| /取消生图 [编号] | 取消自己的任务 |
| /我的额度 | 查询额度 |
| /reset | 重置当前会话 |

群内生成必须实际@机器人，普通聊天和/reset按群触发规则；私聊无需@。/生图和/tag生图不接受附图或图片引用；/高清须先安装并启用。

## 管理员

| 指令 | 用途 |
| --- | --- |
| /help 管理 | 查看完整管理列表，管理员私聊 |
| /关闭生图、/开启生图 | 全局切换普通用户的Comfy生成权限 |
| /刷新模型 | 扫描LoRA并报告缺项 |
| /添加用户 QQ号、/移除用户 QQ号 | 修改私聊白名单 |
| /添加群 群号、/移除群 群号、/白名单 | 修改或查询群白名单 |
| /生图n 描述、/tag生图n PST/正面词 NGT/负面词 | 批量生成 |
| /生图额度 昵称 n | 群内追加本小时额度，重名拒绝 |
| 设置默认生图额度 n | 修改普通用户默认额度 |
| 设置生图额度 QQ号 n | 设置指定QQ额度 |
| 恢复默认生图额度 QQ号 | 移除指定额度 |
| /清理管线 | 取消本机器人未发送任务并清失效锁 |
| /清除生图缓存 | 空闲时清理本机器人图片及视频缓存 |

生成开关、刷新、管线清理支持管理员私聊或已开放群内实际@。白名单和指定额度管理保留私聊限制。关闭生图不会关闭聊天或改变额度，已入队任务继续完成。视频指令仅在安装video扩展后提供，见根EXTENSIONS.md。

远程模式使用/mode agent L2申请，本人确认后生效；每次工具审批仍需本人核对通过。其他指令以/help 管理为准。

## 网页下载（仅安装并启用web-media后）

- /下载图片 链接 [序号] —— 获取网页图片。
- /下载视频 链接 [序号] —— 获取网页视频。
- /下载文件 链接 [序号] —— 获取其他文件。
- /正常抓取、/加密抓取 —— 管理员切换本会话发送方式。
- /清除抓取缓存 —— 管理员清理已结束缓存。

群内需真实@，白名单沿用现有配置。自然语言搜索与批量下载使用reserved2的qq_web_media，未安装时不公开该工具或帮助列表。
